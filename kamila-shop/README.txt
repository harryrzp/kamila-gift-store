KOMUNITAS STORE INDONESIA — KAMILA GIFT STORE

Responsive Last War gift store with Komunitas Store Indonesia branding and Kamila's portrait.

Included:
- Burgundy / pink / gold visual theme
- Header logo treatment inspired by the Becca layout: round Kamila portrait + store name
- Kamila portrait featured in the hero section
- English / Bahasa Indonesia UI toggle (saved in browser)
- Light / Dark / System appearance selector (saved in browser)
- 19 supplied transparent gift WebP assets
- All / VIP / UR / SSR / EVENT gift categories
- Search, quantity controls, cart and WhatsApp order review
- IGN, server, alliance and notes fields
- TikTok contact: @kamilamachrus2
- Payment information section; exact payment brands/details still need Kamila's confirmation
- No PayPal conversion or middleman service

SETUP:
1. Keep the folder structure intact.
2. Open index.html to preview, or upload the whole folder to static hosting.
3. WhatsApp number is configured in js/config.js (preserved from Kamila's original source).
4. To add payment methods, update the payment section in index.html after confirming the actual methods with Kamila.

NOTES:
- Gift images are local assets in assets/gifts/.
- Golden Watch is categorized as EVENT GIFT.
